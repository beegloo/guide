# Formas e interface

Status: ativo
Última revisão: 2026-08-30

## Linguagem

- Superfícies claras e amplas.
- Cards sem borda pesada.
- Separação por tonalidade, respiro e forma.
- Raios generosos.
- Controles arredondados.
- Poucas sombras e baixa intensidade.
- Movimento orgânico usado com intenção.

## Raios de referência

- 16 px para elementos compactos.
- 28 px para cards e painéis médios.
- 44 px para grandes superfícies editoriais.
- Formato de pílula para tags, chips e ações curtas.

Os valores são referências do guia visual atual. Um sistema formal de tokens de interface ainda deve ser homologado.
