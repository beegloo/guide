# Tipos de referência

Status: ativo
Última revisão: 2026-08-31

Classifique cada input visual antes de iniciar uma exploração. O papel define o que deve ser preservado, o que calibra a criação e o que pode ser adaptado.

## Source of truth

Representa um fato real que deve ser preservado fielmente. Inclui, quando aplicável, produto, embalagem, logo, tipografia oficial, cores de marca, naming, textos e preços aprovados.

Não redesenhe, regenere ou substitua esses elementos. Uma source of truth nunca deve ser tratada apenas como inspiração visual, estilizada para combinar com um mood ou substituída por uma aproximação.

## Creative reference

Calibra energia, escala, tensão, ritmo, composição, acabamento e impacto. Deve transformar a composição, não o assunto, e nunca substitui uma source of truth.

## Mood reference

É uma creative reference voltada a atmosfera, ritmo, energia, composição e nível de acabamento. Deve ser traduzida para o sistema Beegloo, não copiada literalmente. Não autoriza reproduzir identidade, produto ou elementos proprietários de outra peça.

## Brand reference

Define identidade, paleta, tipografia, linguagem visual e comportamento da marca. Deve ser aplicada de acordo com seu status e com a [ordem de precedência das fontes](../foundations/sources-of-truth.md).

## Exploratory asset

É um input provisório que pode ser adaptado ou substituído quando o briefing permitir. Seu status deve permanecer explícito para que não seja confundido com fato ou asset oficial.

Quando uma entrega combinar papéis, mantenha-os separados: fontes de verdade limitam a execução factual; brand references orientam identidade; creative references calibram direção; exploratory assets apoiam hipóteses ainda abertas.

**Priority rule: source of truth always overrides creative reference.**

**Use creative references to transform the composition, not the subject.**

**Recompose the product; do not redesign the product.**

## Benchmark não é tipo de referência

Um benchmark é um holdout usado para avaliar qualidade depois da criação. Ele não deve ser classificado como creative input nem carregado durante exploração. Os inputs acima orientam ou limitam o trabalho; os arquivos em `benchmarks/` medem posteriormente uma direção já produzida e congelada.
