# Produto e UI

Status: ativo
Última revisão: 2026-08-30

Este guide orienta interfaces digitais e experiências funcionais: sites, aplicativos, dashboards, portais, fluxos de serviço e ferramentas internas.

## Prioridades do canal

- Hierarquia funcional e previsível.
- Navegação clara.
- Estados e feedback compreensíveis.
- Controles com função semântica.
- Densidade adequada à tarefa.
- Acessibilidade, responsividade e interação por teclado e toque.
- Consistência entre telas e fluxos.

## Gramática de interface

Cards, grids, componentes, spacing, raios e controles arredondados podem estruturar informação e comportamento quando cumprem uma função real. Não devem existir apenas para decorar ou fragmentar conteúdo.

Referências atuais, ainda sem sistema formal de tokens homologado:

- 16 px para elementos compactos.
- 28 px para cards e painéis médios.
- 44 px para grandes superfícies editoriais.
- Formato de pílula para tags, chips e ações curtas.

Esses valores pertencem à aplicação de UI e não são regras universais para marketing, embalagem, fotografia, PDV ou menu boards.

## Relação com a marca

Use Outfit, a paleta canônica, formas macias, superfícies claras e respiro conforme a tarefa permitir. A identidade não substitui requisitos de usabilidade, e padrões de UI não devem ser exportados automaticamente para peças publicitárias.
